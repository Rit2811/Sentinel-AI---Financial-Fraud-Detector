WINDOWS QUICK START
1. Install/start Docker Desktop using Linux containers and the WSL2 backend.
   Use an SSD-backed location. Internet is required for image/dependency downloads.
   The documented setup targets Linux amd64; ARM needs compatible builds/emulation.
2. Extract the ZIP completely to a permanent folder on YOUR computer.
   Do not run commands inside the ZIP viewer. All required private files are
   already at the correct paths within the extracted project folder.
3. Open PowerShell in the extracted Sentinel-AI---Financial-Fraud-Detector folder.
4. Run the following commands, replacing your_name with your reviewer identity
   (letters, numbers, underscore or hyphen):

powershell -NoProfile -ExecutionPolicy Bypass -File scripts/new-teammate-env.ps1 -ReviewerId your_name
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/teammate.ps1 build -Scoring
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/teammate.ps1 start -Scoring
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/teammate.ps1 health
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/teammate.ps1 status

The first command creates YOUR four fresh secrets and a fresh run ID locally.
Run it only once; it refuses to overwrite an existing .env.teammate.local file.
Keep the extracted folder in place after generating your configuration.

Dashboard:              http://localhost:15173
API docs:               http://localhost:18000/docs
Infrastructure check:   http://localhost:18000/ready
